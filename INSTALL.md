# Install New Tab Dashboard

1. Download `new-tab-dashboard-<version>.zip` and **extract** it to a folder you will keep (Chrome reads the extension from this folder, so do not delete it).
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and choose the extracted folder (the one containing `manifest.json`).
5. Open a new tab. Your dashboard appears.

## Optional: local files
To open local files or HTML dashboards, open the extension's **Details** on `chrome://extensions` and turn on **Allow access to file URLs**.

## Updating
Extract the new ZIP over the old folder (or to a new one), then click the reload icon on the extension card. Your data stays: it is stored in Chrome, not in the folder. Use **Settings > Export backup** first if you want a copy.

## Removing
Click **Remove** on `chrome://extensions`. This deletes the saved data too, so export a backup first.
