# Privacy policy: New Tab Dashboard

_Last updated: 21 October 2026 (v1.0.0)_

New Tab Dashboard does not collect, sell or share personal data. It has no account, analytics or tracking, and the developer receives none of your data.

**What is stored.** Your tasks, notes, links, settings, layout and any background image you upload are saved only in your browser using `chrome.storage.local`. The extension has no data-sync service. Removing the extension deletes them. Backups you export are files you save yourself, so keep them private.

**Permissions.** The extension requests only `storage`, to save the data above. It does not read your browsing history or the pages you visit.

**Network requests.** The extension loads no remote code. It sends nothing to any third party: saved links show a letter tile rather than a site icon, so no saved address is ever transmitted. Links you open, including the optional Ko-fi link, go to those sites in a normal browser tab.

**Local files.** If you enable "Allow access to file URLs", the dashboards card reads the title of local HTML files you add, on your computer only. Nothing is uploaded.

**Contact.** Questions or concerns: https://github.com/akaaja2/chrome-newtab-dashboard/issues
