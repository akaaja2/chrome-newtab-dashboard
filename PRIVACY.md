# Privacy policy: New Tab Dashboard

_Last updated: 8 October 2026_

New Tab Dashboard does not collect, sell or share personal data, and has no account, analytics or tracking.

**What is stored.** Your tasks, notes, links, earnings entries, settings, layout and any background image you upload are saved only in your browser using `chrome.storage.local`. They never leave your computer through this extension. Removing the extension deletes them. Backups you export are files you save yourself.

**Permissions.** The extension requests only `storage`, to save the data above.

**Network requests.** The extension loads no remote code. One feature contacts a third party: saved web links show a site icon fetched from Google's favicon service (`google.com/s2/favicons`), which receives the domain of the link.
